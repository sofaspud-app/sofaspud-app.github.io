<p align="center">Your computer, from the couch. See and control your Mac or Windows PC from your iPhone.</p>

## Install

**Mac**
1. Open **SofaSpud.dmg** and drag **SofaSpud Host** onto **Applications**.
2. Open SofaSpud Host from Applications. A pairing code appears.
3. If macOS asks, allow **Screen & System Audio Recording** and **Accessibility** — the pairing window shows you where.

**Windows**
1. Run **SofaSpud-Setup.exe** and click through the installer.
2. If Windows says *"Windows protected your PC"*, click **More info**, then **Run anyway**.
3. A pairing code appears when it's done.

**iPhone**
- Open SofaSpud, tap **Add a computer**, and scan the code (or pick your computer under **Nearby** and type it).
- The iPhone app is in beta testing for now, through TestFlight.
